# ЭкоТропа · Торфяное

### Больше, чем прогулка

Мобильная научная тропа у озера Торфяное в районе Патрокла, Владивосток. Пять небольших расследований помогают увидеть за привычным пейзажем биологию, физику и связи живого мира. Посетитель наблюдает, делает выбор, читает короткую статью и получает свой игровой образ — от крепкой скалы до лёгкой на подъём бабочки.

Приложение открывается в браузере телефона или внутри Telegram. Регистрация, установка из магазина и платные сервисы не нужны.

## Что внутри

| Станция | Что делает посетитель | Что узнаёт |
|---|---|---|
| **01 · Озеро в несколько этажей** | Выбирает место для утки и наблюдает за водоёмом | Укрытия, коллективная бдительность, плавательный пузырь и фильтрация |
| **03 · Невидимый город Торфянки** | Отличает природные прототипы от придуманного героя | Пищевые связи и жизнь в масштабе капли |
| **05 · Хвойное расследование** | Ищет четыре признака, по желанию фотографирует находки | Чем отличаются сосна, ель, пихта и можжевельник |
| **08 · Почему стальной корабль не тонет** | Перемещает детали, испытывает судно или смотрит рабочий пример | Сила Архимеда, центр тяжести и продольный баланс |
| **10 · Два мира стрекозы** | Наблюдает, читает историю, отвечает «правда / ложь» | Водная личинка, экзувий, метаморфоз и различия зрения |

Станции 2, 4, 6, 7 и 9 остаются явно обозначенными будущими точками. Финал открывается после **пяти доступных станций**, без ожидания остальных.

**Станция 8 не блокирует чтение.** Кнопка перехода к статье и рабочий пример доступны с самого начала. После первой неудачи, в том числе при неполной сборке, сразу появляется объяснение и предложение читать дальше.

## Запустить на Mac / Linux

Нужен Python **3.12+**. Команда на macOS — `python3`, а не `python`.

```bash
cd eco-trail
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 run.py
```

Открой **http://localhost:8000**. Остановка — `Ctrl+C`.

На Windows активация окружения: `.venv\Scripts\activate`; при необходимости вместо `python3` используй `py -3.12`.

Чтобы проверить с телефона в той же Wi-Fi-сети, открой `http://ЛОКАЛЬНЫЙ_IP_КОМПЬЮТЕРА:8000`. `localhost` на телефоне — сам телефон. Офлайн-кэш и часть возможностей браузера требуют HTTPS; локальный `localhost` является исключением.

## Запустить через Docker

Нужны Docker Engine / Docker Desktop и Compose v2.

```bash
cd eco-trail
docker compose up -d --build
```

Приложение доступно на **http://localhost:8000**. Порт привязан к loopback и не открыт в интернет.

```bash
docker compose logs -f web
docker compose down
```

Для проверки с другого устройства удобнее локальный Python-запуск выше или HTTPS-развёртывание ниже.

## Сервер и HTTPS

Подготовь домен или поддомен и сервер с Docker. A-запись домена должна указывать на сервер; если есть AAAA-запись, IPv6 тоже должен вести на этот сервер. Открой входящие TCP 80 и 443. UDP 443 необязателен, нужен для HTTP/3. Другой веб-сервер не должен занимать эти порты.

Скопируй **содержимое папки `eco-trail`** на сервер. В этой папке:

```bash
cp .env.example .env
```

Укажи в `.env` настоящие значения **без `https://` у домена**:

```dotenv
DOMAIN=trail.your-domain.ru
ACME_EMAIL=you@your-domain.ru
```

Затем:

```bash
docker compose -f compose.production.yaml up -d --build
```

Caddy автоматически получает и обновляет сертификат. Приложение доступно по `https://trail.your-domain.ru`. База данных и токен Telegram для этой версии не нужны.

```bash
# Проверить готовность
curl https://trail.your-domain.ru/healthz

# Посмотреть ошибки запуска и выдачи сертификата
docker compose -f compose.production.yaml logs --tail=100

# Обновить код или открыть новую станцию
docker compose -f compose.production.yaml up -d --build
```

Прогресс хранится в браузере посетителя, поэтому пересборка сервера его не удаляет. Смена домена, очистка данных браузера или другой телефон создают отдельное прохождение. Не меняй `id` опубликованных станций и блоков без необходимости.

Если сервер уже обслуживается Nginx/Caddy, используй обычный `compose.yaml` и проксируй свой HTTPS-домен на `127.0.0.1:8000`. Второй Caddy запускать не нужно.

## Подключить Telegram Mini App

1. Создай бота через **@BotFather → `/newbot`** или выбери существующего.
2. Сначала проверь, что **HTTPS-адрес приложения** открывается на телефоне.
3. У @BotFather отправь **`/setmenubutton`**, выбери бота, укажи адрес приложения и подпись, например **«Открыть экотропу»**. Также доступен путь **Bot Settings → Menu Button**.
4. По желанию настрой основное мини-приложение через **Bot Settings → Configure Mini App**.
5. Открой бота на телефоне и нажми кнопку меню.

Используется тот же HTTPS-адрес, что и в обычном браузере. Вручную вставлять токен бота в JavaScript или `.env` приложения **не требуется**. SDK Telegram используется для раскрытия окна, цвета интерфейса, кнопки назад и тактильного отклика; отказ SDK не блокирует прохождение.

Эта версия не отправляет сообщения и не использует Telegram ID. Если позже появится личный кабинет или сохранение на сервере, нужно отдельно реализовать проверку `initData` на backend: нельзя доверять данным клиента. [Официальная документация Telegram](https://core.telegram.org/bots/webapps).

## Как считаются результаты

У персонажа пять черт: **опора, открытость, внимание, замысел, связь**. Каждый ответ в `choice` или `profile_choice` добавляет веса из поля `scores`. Ответ записывается по паре `станция:блок`; повторный клик не добавляет очки, смена ответа заменяет старый выбор.

Для каждой черты сумма делится на сумму её максимально возможных баллов в отвеченных вопросах. Это уменьшает перекос из-за разного количества баллов в вариантах. В финале показаны исходные числа и полоски нормированного результата. При точном равенстве приложение сообщает о смешанном образе; порядок отображения равных результатов фиксирован: скала, бабочка, цапля, стрекоза, сосна.

Отдельно начисляются **научные открытия**: до 4 за распознавание микрожителей и до 5 за «правда / ложь». Вопросы учитывают первый подтверждённый ответ. Ошибки сразу объясняются, путь дальше остаётся открытым. На личностный образ эти баллы не влияют.

Это развлекательный тест с прозрачной логикой, **не клиническая диагностика и не обученная ML-модель**.

## Телефон, фото и работа без сети

- Макет проверен на ширинах **320, 390 и 430 px**; кнопки, текст и конструктор не выходят за экран.
- Для судна есть касания и перетаскивание. Для клавиатуры работает выбор кнопками.
- Можно проходить станции в произвольном порядке. Состояние блоков и ответы восстанавливаются.
- Фото необязательны. Изображение уменьшается до 1200 px по длинной стороне и сохраняется в IndexedDB; на сервер ничего не загружается.
- При недоступном `localStorage` прохождение продолжает работать в текущей вкладке с понятным уведомлением.
- Service Worker сохраняет локальные статьи, интерфейс и схемы после первой успешной загрузки. Telegram может требовать сеть для самого открытия WebView; гарантировать автономный старт внутри Telegram нельзя.
- Таймер наблюдения добровольный; отсчёт опирается на время, а не число срабатываний таймера.
- Поддерживается системная настройка уменьшения анимаций.

**Справочные фото хвойных сейчас загружаются с Wikimedia.** При недоступной сети вместо них показываются подписанные локальные схемы. Чтобы включить фотографии в серверную сборку и офлайн-кэш, перед Docker-сборкой выполни:

```bash
python3 scripts/bundle_photos.py
```

Среда подготовки архива не разрешила скачать эти оригиналы (HTTP 403). Все ссылки, авторство и лицензии сохранены в [ASSETS.md](docs/ASSETS.md). Собственные фотографии находок работают независимо от внешних источников.

## Как устроен проект

```text
eco-trail/
  app/
    main.py                 — сервер, API и офлайн-версия
    stations/
      __init__.py           — поиск файлов и валидация маршрута
      station_01.py ...     — тексты, задания и баллы
    static/
      index.html            — оболочка
      app.js                — экраны, события и сохранение прогресса
      core.js               — чистые функции баллов и модели судна
      photos.js             — локальное хранилище фотографий
      styles.css            — адаптивная тема Патрокла
      sw.js                 — работа без сети
      media/                — локальные SVG-схемы
  docs/                     — проект, расширение, источники и проверки
  scripts/bundle_photos.py   — загрузка лицензированных фото
  tests/                    — API, расчёты и мобильный маршрут
  Dockerfile
  compose.yaml
  compose.production.yaml
  Caddyfile
```

Нет сборщика frontend, сторонних шрифтов, CDN-карт и обязательной аналитики. Node.js нужен только разработчику для JS-тестов и форматирования; для обычного запуска достаточно Python или Docker.

## Открыть следующую станцию

Отредактируй соответствующий `app/stations/station_XX.py`: `status: 'active'`, содержимое `blocks`, связки `next_block_id` и `completion`. Или добавь новый файл `station_11.py` с объектом `STATION`. После перезапуска сервера станция автоматически появится в маршруте, подсчёте прогресса и условиях финала.

Менять HTML, JavaScript или список импортов не нужно, если используются существующие механики. Для принципиально нового типа игры понадобится новый рендерер — это честная граница расширяемости. [Контракт и готовый пример](docs/ADD_STATION.md).

```bash

Полный мобильный прогон:

npm install
npx playwright install chromium

```

Подробный результат и границы проверки — в [TESTING.md](docs/TESTING.md). Docker-движок и реальный Telegram на iOS/Android в среде сборки недоступны; запуск контейнеров на сервере и полевой проход остаются проверкой перед публичным анонсом.
