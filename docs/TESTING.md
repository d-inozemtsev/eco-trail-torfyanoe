# Проверки сборки

## Выполнено

- **5 Python-тестов:** выдача маршрута и ресурсов, health-check, Service Worker, некорректные ID блоков/переходы/баллы, контракт новой станции.
- **5 JS-тестов:** замена ответа без накопления очков, независимость научных баллов от профиля, неполное и неправильное судно, рабочая сборка, посторонние ответы и детерминированный результат.
- **75 проверок в Chromium:** полное прохождение всех пяти станций при ширине **320, 390 и 430 px**, отсутствие горизонтального переполнения на каждом шаге, отсутствие ошибок JavaScript, финал после пяти станций, сохранение результата после перезагрузки, добавление фотографии, отказ localStorage и повторное открытие без сети через Service Worker.
- Внешние SDK и изображения были намеренно заблокированы в мобильном тесте: проверена работоспособность при их недоступности.
- Визуально просмотрены главный экран, станция 8 и финальный результат. Скриншоты `home-mobile.png` и `result-mobile.png` находятся рядом.

Для браузерного прогона использован Chromium 138 в режиме эмуляции мобильного viewport и touch-capable устройства. Это не аппаратный тест на реальном iPhone или Android.

## Команды

Из корня `eco-trail`:

```bash
python3 -m pip install -r requirements-dev.txt
python3 -m pytest -q
node --test tests/core.test.js
npm install
npx playwright install chromium
npm run test:e2e
```

`mobile.cjs` сам запускает сервер на `127.0.0.1:8765`, выполняет сценарии и останавливает его. Для нестандартного окружения доступны переменные `PYTHON`, `PLAYWRIGHT_MODULE` и `QA_CHROMIUM_PATH`.

## Не проверено в этой среде

Docker-движок, реальная выдача TLS-сертификата, открытие через BotFather, Telegram WebView на физическом iOS/Android, нативный диалог камеры и аппаратное перетаскивание пальцем. В этой среде нет Docker и подключённых телефонов. Конфигурации подготовлены; подтвердить их работу в целевом окружении нужно после размещения.

Справочные фотографии подключены по источникам с лицензиями, но оригиналы не включены в архив из-за HTTP 403 при скачивании. Тест проверял локальные резервные схемы, не доступность Wikimedia на устройстве посетителя.

Перед публичным анонсом нужен проход по территории: сверить координаты и виды растений, проверить связь, доступность дорожек и понимание текстов детьми. Эти полевые условия не проверяются автоматическими тестами.
